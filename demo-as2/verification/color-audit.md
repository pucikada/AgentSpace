# 设计系统与颜色变量审校记录

日期：2026-11-10（America/Los_Angeles）。范围：用户提供的 DESIGN-v2.1 修订稿与 demo-as2 的当前实现。

## 审查结论

原稿方向正确，但不能视为完整规范。主要缺口与本次修正：

| 原问题 | 处理 |
| --- | --- |
| 用户可见 4 风格、底层 6 标识与组件库 8 主题混用 | 产品按 4 风格 / 10 基准组合定义；DevUI 独立维护 |
| 像素“默认深色”与实际初始化不同 | 区分 CSS 深色基础块、产品浅色初始化 |
| 幻彩浅/映衬合列、旧对比度表采用八列 | 分成 10 列，使用浏览器级联值与同一组颜色重算 |
| 148/160 等历史变量计数不能证明全量 | 现登记 182 个产品/兼容语义变量，225 个 CSS 作用域与 28 个字面量运行时写入槽 |
| 双层桥接方向不清、尚未实施的扩展被当成已有 | 落地五个最小 DevUI 兼容别名；其余明确为未来适配要求 |
| CSS、阴影、渐变、var fallback、JS 色板、SVG 仍有裸色 | 固定颜色集中到 palette.css，共 843 项（包含 RGB 通道、固定图像与算法参数）；界面通过变量引用 |
| 文件色/分类色/看板 waiting 不一致，兼容变量缺失 | 增加分类/文件/项目语义层；waiting 使用 as-wait；补齐已有别名 |
| 从旧 MVP 完整重建会丢失新幻彩/Bento/产品逻辑 | 默认重建从当前 index 同步，旧导入路径标为历史用途 |
| build.py 会覆盖手改表 | 新文档使用独立快照与生成器；加入生成结果同步检查 |
| 将短词、placeholder、控件边界混用错误门槛 | 文字与非文本规则分开；保留未达标项，不伪装为通过 |

审查开始时，下载的线上 demo 与本地 index.html 字节一致。随后工作区有另一组菜单样式更新，本次保留了这些增量，仅把其新增透明背景字面量接入已有变量。没有发布 GitHub Pages。

## 保留的风险与边界

默认快照仍存在少量低于普通文字 4.5:1 的组合：Bento 浅色 brand/card 约 3.47、Bento 深色 subtle/card 约 3.83、幻彩浅/映衬 brand/card 约 4.41、玻璃 fail/card 约 4.23。详细值在 DESIGN.md §13。本次没有擅自调整视觉配色；应按这些 token 的真实文字/图形用途评估，而非宣称全页 WCAG 合格。

玻璃对比度是默认画布上的近似合成，没有覆盖任意照片壁纸、所有透明度/折射参数、自定义强调色和渐变每个位置；也没有穷举所有 hover/focus/disabled 状态。固定照片、头像、品牌图像的像素不属于 CSS 颜色硬编码。

旧 MVP 备份与独立 DevUI vendor 不是当前产品 UI 源，未批量修改。最新整页逻辑仍有一部分仅在 index 中；本次通过保留当前整页的构建方式防止回退，没有借此开展无关的整页模块化重构。
